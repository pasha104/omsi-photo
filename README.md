# OMSI PHOTO

Независимая фотобаза скриншотов из OMSI 2 и OpenOMSI.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages:
1. Repository → Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Branch: `main`, folder: `/ (root)`.
4. Нажмите Save.

После публикации сайт будет доступен по адресу:
https://pasha104.github.io/omsi-photo/

## Что уже работает
- Адаптивная главная страница для телефона и компьютера.
- Галерея с поиском, фильтрами по симулятору и типу транспорта.
- Карточки фотографий и просмотр деталей.
- Добавление JPG, PNG и WebP до 8 МБ.
- Локальное сохранение загруженных изображений через IndexedDB.
- Категории автобусов, троллейбусов, трамваев, интерьеров и карт.

## Важно: текущий этап
Это стартовая клиентская версия. Загруженные фотографии пока хранятся только в браузере того устройства, с которого их добавили. Демонстрационные карточки — примеры интерфейса, не реальные снимки пользователей.

Регистрация, единая база фотографий, комментарии, публичные профили и модерация требуют подключения серверной части (например, Supabase Auth, Database и Storage) с настройкой политик доступа RLS. Не размещайте секретные ключи в публичном репозитории.

## Структура
- `index.html` — разметка страниц и диалогов.
- `styles.css` — оформление и адаптивность.
- `app.js` — галерея, фильтры и локальное хранилище.
